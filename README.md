# Muscle Mommy

A mobile-first workout tracker built with Next.js, React and TypeScript. Progress is saved privately in the browser using localStorage.

## Run locally

1. Install Node.js 20.9 or newer.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000.

## Put it on GitHub

Create a new empty repository named `muscle-mommy` under `lisakmclaugh-dev`, then run:

```bash
git init
git add .
git commit -m "Build Muscle Mommy v1"
git branch -M main
git remote add origin https://github.com/lisakmclaugh-dev/muscle-mommy.git
git push -u origin main
```

## Deploy to Vercel

1. Sign in to Vercel with GitHub.
2. Choose **Add New > Project**.
3. Import `lisakmclaugh-dev/muscle-mommy`.
4. Keep the detected Next.js defaults and choose **Deploy**.

## Current features

- Pastel mobile dashboard
- Monday, Wednesday, Friday and Saturday workouts
- Gym/home Saturday choice
- One-exercise-at-a-time workout flow
- Set checkboxes and weight entry
- Browser-based completed-workout history
- Current and longest streaks
- Monthly completion calendar
- Personal-best tracking
- Workout notes and difficulty rating
- Installable web-app manifest

## Important

This app is general fitness tracking, not medical advice. A young beginner should use age-appropriate loads, focus on technique, and train with qualified adult supervision.
